# Kreovant Asset Flip Lab: 20 Real Downloadable Assets
_Last reviewed: 2026-10-22 · Research shortlist, not yet modified or released_

## Correct objective

Acquire existing downloadable assets, inspect their rights, improve them substantially, package the improvements, and sell the resulting product where the license permits. This catalogue lists **20 actual templates/kits**, not 20 ideas for plugins.

## Rules

- "Free download" is not a license. Keep the original license and required notices with redistributed source.
- MIT-licensed source can generally be modified, redistributed, and sold subject to retaining the copyright and license notice. It does **not** grant rights to separately licensed demo images, fonts, logos, or other bundled assets.
- Replace demo images with original/licensed images before packaging. Audit fonts, icons, illustrations, dependencies, and any hosted assets separately.
- Don't sell unchanged work as if Kreovant created it. Add meaningful value: responsive redesign, modern dependencies, accessibility, reusable variants, industry-specific content, documentation, Figma files created by us, setup automation, or a tested bundle.
- Do not remove upstream attribution/license files. Do not use upstream trademarks as our brand.
- Before listing an item, download it, read the current full license and marketplace terms, inspect all bundled assets, run it, and log the commit/version and checksums.
- This is a research shortlist. No item has yet been downloaded, fully audited, modified, or published as a Kreovant product.

## Best first bets

Prioritize assets that can become a focused, differentiated pack without expensive infrastructure.

1. **Resume / portfolio pack (#11):** package for Indian freelancers and early-career designers; add print-ready CV layout, case-study pages, and a deployment guide.
2. **Agency / studio pack (#8):** add premium case-study layouts, service-page variants, and a cohesive design system.
3. **Shop Homepage (#20):** create a clean small-business storefront starter and document how to connect it to a real checkout. Do not imply the demo checkout processes payments.
4. **Delta or Flux (#1–2):** use only after inspecting the actual downloaded files and separate asset licenses. Add original components and documentation rather than merely recoloring them.

These are hypotheses, not proven sales forecasts. Validate interest with a demo page, a waitlist, or conversations before spending money.

## 14-day repeating acquisition-to-sale cycle

| Day | Stage | Action | Gate |
|---:|---|---|---|
| 1 | Discover | Find assets with real source/download links and a clear audience | Candidate and upstream URL recorded |
| 2 | Acquire | Download source and record version, date, and SHA-256 checksum | Original archive preserved |
| 3 | License | Read full license and marketplace terms; inspect images, fonts, icons, dependencies | PASS / REVIEW / BLOCKED; no unresolved rights treated as permission |
| 4 | Demand | Review competing listings, user complaints, and requested features | At least three concrete pain signals or demand marked unproven |
| 5 | Select | Score impact, improvement effort, rights, competition, and support burden | One small scoped asset selected |
| 6–8 | Improve | Create a meaningful redesign/feature pack, original content, or workflow | Improvement is demonstrable, not just a logo swap |
| 9 | QA | Test responsiveness, accessibility, install/build, links, and clean setup | QA checklist passes |
| 10 | Package | Write instructions, changelog, attribution, license bundle, screenshots, and limitations | Buyer can use it without personal help |
| 11 | Legal/marketplace gate | Recheck source and third-party rights; review seller/platform terms | No blocking issues remain |
| 12 | Publish | List on Kreovant site and an appropriate marketplace if permitted | Listing URL and version recorded |
| 13 | Measure | Track views, clicks, downloads, purchases, refunds, and support requests | Real metrics recorded |
| 14 | Decide | Improve, bundle, maintain, or archive; reinvest only based on evidence | Decision and next cycle logged |

## Required asset ledger

For every item, add these fields before any commercial release:

- Original asset name and upstream URL
- Date acquired, release/version, source commit, and SHA-256 checksum
- Exact license text and required notices
- Separate asset/dependency license inventory
- What Kreovant changed, with before/after screenshots
- QA results and known limitations
- Target customer, competing products, price hypothesis, and validation evidence
- Product listing URL, sales, refunds, and next action

## Budget guardrail

First cycle stays under ₹5,000. Prefer free tooling and organic validation. Do not pay for ads, premium assets, or infrastructure before a specific asset passes rights review and users show interest. Pricing is to be tested, not guessed into existence.
