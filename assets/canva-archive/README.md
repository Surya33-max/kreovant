## Export instructions

1. Open each Canva edit link.
2. Choose **Share → Download**.
3. Export in the format needed for the deliverable (PDF for multi-page documents, PNG for individual graphics, MP4 for supported videos).
4. Save exports into this folder, using concise filenames based on the design title.
5. Keep editable originals in Canva. Some entries may be duplicates or imported PDFs; review before archiving.

## Limitation

The connected Canva tools available for this task can search and inspect designs, but do not provide a direct bulk-download/export operation. This repository currently stores the index and links, not the original design binaries.
